A USB hard drive can look like a simple storage upgrade, but a PlayStation 5 treats different kinds of games differently. For the Seagate 2TB Game Drive, the first buying question is not how much space it adds. It is which games you expect to start straight from the drive.

This checklist uses PlayStation and Seagate support pages and the exact Amazon product page. We have not used this drive, timed any game load, or compared it with another model. It does not quote a price, discount, stock level or customer rating, and the sources below do not promise that every drive works with every console.

## Can PS5 games be played from USB extended storage?
No. Sony states that PS5 games cannot be played directly from USB extended storage. You can move finished games or games you have not played in a while to the drive, then copy the game data back to console storage when you want to play again.

That makes this kind of drive an archive for PS5 titles rather than extra play space. If your plan is to fill the drive with PS5 games and launch them from it, this is the wrong tool. The [PS5 M.2 SSD checklist](/guides/ps5-m2-ssd-checklist/) covers the internal storage path, which is a separate decision.

## What can the drive do for PS4 games?
Sony says you can set USB extended storage as the install location for PS4 games and play them directly from it. So the drive is useful if you keep a library of PS4 downloads and want them off the console's internal storage.

Seagate's product text matches that split: it describes archiving PS5 games on the drive and playing PS4 games directly. Both companies use the same distinction, so write down how many of your games are PS4 titles before you decide. If most of your library is PS5 games, the benefit shrinks to storing games you are not playing right now.

## Which drive requirements does PlayStation list?
PlayStation lists a SuperSpeed USB 5 Gbps connection or faster, with a capacity from 250 GB to 8 TB. It also says that not every device is guaranteed to work with the console. The Seagate listing names a 2 TB capacity and a USB 3.0 interface, which fits inside that range.

A capacity or interface number on a listing is not the same as a guarantee. Treat the Sony page as the rule and the product page as a description of this drive. Keep the exact model number, STLV2000101, with your order notes so you can match it to Seagate's own pages.

## What connection mistakes should you avoid?
Sony says the drive cannot be connected through a USB hub, and that two or more extended-storage drives cannot be used at the same time. Seagate adds that USB storage is not compatible with the USB Type-A port on the front of the PS5, so Type-A storage must use a rear port.

Before ordering, look at which rear port is free and whether anything else already sits there. Also remember that a drive set up as PlayStation extended storage will need to be reformatted before Windows or macOS can use it again, according to Seagate. That makes it a poor choice if you plan to share one drive between a console and a computer.

## Who should choose a different storage option?
Choose a different option if you want PS5 games to start from the storage itself. In that case, an internal M.2 drive that meets Sony's requirements is the path to compare, not a USB drive. Also look elsewhere if you need a drive that also serves a computer without being reformatted.

Someone who mostly plays one or two large PS5 games may not need an archive drive at all. A USB drive helps when you rotate through many games and want to avoid downloading them again. If you mostly buy digital games, the [disc versus digital checklist](/guides/ps5-disc-vs-digital-checklist/) is a useful place to estimate how much storage you will need. That is a convenience point, not a speed or quality claim.

## What should you write down before ordering?
Write down the exact product name, the model number, and the capacity. Add the rear USB port you will use, the number of PS4 games you want to keep, and whether you want to move PS5 games back and forth. Then check Sony's current extended-storage page for the console you own.

If those notes match, this drive is a candidate for a library of PS4 games and archived PS5 games. If any item is unclear, such as the port or whether a hub would be involved, settle it first. The goal is storage that fits how the console treats each type of game, not a drive that surprises you at the first launch.
