Most microSD advice online was written for the first Switch, and a card that was perfect there can be useless in a Switch 2. This checklist looks at one specific listing, the Nintendo-licensed SanDisk microSD Express card in 256 GB, and asks whether it matches what Nintendo says the new console accepts.

It uses Nintendo's support page, SanDisk's own card pages and the exact Amazon product page. We have not used this card, put it in a console or timed a download. It quotes no price, discount, stock level or customer rating, and it does not rank the card against other brands.

## Does Switch 2 accept this kind of card at all?
Yes, if it is a microSD Express card. Nintendo's support page says Nintendo Switch 2 is only compatible with microSD Express cards, and its compatibility table marks ordinary microSD cards as not supported on Switch 2. SanDisk lists a 256 GB microSD Express card for Nintendo Switch 2 on its own site, and the Amazon listing names it as the Nintendo SanDisk microSD Express Card for Nintendo Switch 2.

That wording is the part to match. A card sold simply as a fast microSD card, even a very fast one, is a different product from a microSD Express card. The longer background is in our [Switch and Switch 2 microSD guide](/guides/switch-microsd-card-checklist/).

## What happens to a card you already own?
Nintendo warns that a microSD card previously used on a Nintendo Switch console will not let you save or load digital games or save data when it is inserted into a Switch 2. The same table says it is still possible to load screenshots and videos from such a card.

So the practical rule is to treat a Switch card as a card for the Switch. If you want to keep using the old console, a microSD Express card also works there, but Nintendo says its read and write speed on a Switch matches an ordinary microSD card. Buying Express only for the old console would not add speed.

## What should you do the first time you use it?
Nintendo notes that a system update through the internet is required the first time you use a microSD Express card. Plan for that before you sit down with a new card, because a console that is offline or out of date is the likeliest reason a correct card seems not to work.

Nintendo also says microSD Express cards with a capacity of up to 2 TB are supported, so 256 GB sits well inside the supported range. How many games fit depends on the games you own, and we have not counted any.

## Which details on the Amazon listing should you read twice?
The page we opened is titled Nintendo Switch 2 Micro SD Card, SanDisk, with the edition shown as Standard Edition. The detail table names the brand as Nintendo, the model name as Nintendo SanDisk microSD Express Card for Nintendo Switch 2, the model number as 10016157 and the manufacturer part number as BEE-A-SD01A. It lists the memory capacity as 256 GB. The page was filed under Video Games, then Nintendo Switch 2, then Accessories.

Two details do not line up neatly. The listing's read speed line shows 800 megabytes per second, while SanDisk's own pages list up to 880 MB/s read and up to 650 MB/s write for the 256 GB card. SanDisk also uses its own model code for the 256 GB card, SDSQXFN-256G-GR6ZZ, which is not the code shown on the Amazon page. We left all speed numbers out of the decision and did not assume the two codes describe the same item.

## Who should skip this card?
Skip it if you only plan to use the Switch 2 for physical games and never download anything, because the card has no use there. Skip it too if you need a size other than 256 GB, since SanDisk's data sheet lists 512 GB and 1 TB versions as separate capacities that this listing does not cover.

Also skip it if a different brand's microSD Express card is the one you already own. Nintendo's rule is about the card type, not one brand, and nothing here argues for replacing a card that already meets it. Browse more options in our [storage aisle](/category/storage/).

## What should you write down before ordering?
Write down the exact product name, the 256 GB capacity, the words microSD Express and Nintendo Switch 2 from the title, and the model number shown in the detail table. Add Nintendo's three warnings: Express only, old Switch cards will not carry digital games, and a system update on first use.

If every line matches, the card is a reasonable candidate for adding Switch 2 storage. If the listing you land on shows a plain microSD card, a different capacity or a different model number, stop and read that page fresh. The goal is a card the console accepts on the first try, not one that only looks right in a photo.
